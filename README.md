# Ева и Эра — сборки приложения

Здесь лежат только готовые сборки семейного приложения «Ева и Эра» для Android
и файл `update.json`, по которому приложение само находит обновления.

Исходного кода, рисунков-заготовок и фотографий здесь нет.

## Как установить

1. Открыть на телефоне страницу последнего выпуска:
   https://github.com/3dgopnik/evaera-releases/releases/latest
2. Скачать файл `evaera.apk` и установить его (Android попросит разрешить установку).

Дальше приложение обновляется само: Меню → «Обновления».
